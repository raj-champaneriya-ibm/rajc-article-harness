# Voice guide

The drafter and reviser read this file before writing. The style learner proposes
changes by pull request; nothing changes here without your approval.

## Seed rules (from the rajc.work site guide)

- Open with an executive-accessible paragraph that states the business outcome.
- Frame technical decisions as cost, risk, time or career impact.
- Quantify claims when you can; mark the gap with `[TK: ...]` when you cannot.
- Write titles that intrigue a CTO, not only a practitioner.
